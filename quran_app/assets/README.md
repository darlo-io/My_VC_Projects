# Графические ассеты

## `images/backgrounds/`

| Файл | Формат | Размер | Назначение |
|------|--------|--------|------------|
| `home_background.webp` | WebP (q=82) | 1080×2400, ~20 КБ | Главный экран: мечеть в правом верхнем углу + кремовая левая половина |

**Регенерация:**

```bash
py tool/build_home_background.py
```

Скрипт берёт `docs/images/background.webp` (исходник 941×1672),
вырезает правую верхнюю часть с мечетью, вписывает её в правую
верхнюю четверть целевого полотна 1080×2400 (с кремовым фоном
`AppColors.background`) и сохраняет в WebP.

В UI картинка используется с `BoxFit.cover` и `alignment: topRight`,
поэтому на любых пропорциях экрана мечеть остаётся в правом
верхнем углу.

## `icons/home/`

PNG-иконки главного экрана, извлечённые из дизайн-макета
(`docs/images/75a732c8-*.png`).

| Файл | Назначение | Размер |
|------|------------|--------|
| `settings.png` | Шестерёнка настроек (header) | 180×170 |
| `quran_rehal.png` | Коран на подставке (rehal) в карточке «Продолжить чтение» | 380×440 |
| `read.png` | Открытая книга на подставке (Читать) | 370×350 |
| `listen.png` | Наушники (Слушать) | 350×350 |
| `learn.png` | Шапочка выпускника (Учить) | 370×350 |
| `test.png` | Планшет с заметками (Тест) | 350×350 |
| `tasbih.png` | Чётки (Тасбих) | 370×340 |
| `stats.png` | Диаграмма (Статистика) | 350×340 |

Иконки имеют прозрачный фон вокруг объекта — круглая форма
создаётся через `ClipOval` / `BoxShape.circle` в UI-слое.
Разрешение увеличено ×2 от исходного макета для чёткости на
xxxhdpi экранах.

**Регенерация** (если изменился макет):

```bash
py tool/extract_mockup_icons.py
```
