## 3. MVP v0.1 — Чтение

### 3.1 Фундамент — ✅ Реализовано
- ✅ Flutter-проект `quran_app/` инициализирован, `analysis_options.yaml`, `flutter_lints ^6.0.0`.
- ✅ Подключены `flutter_riverpod ^2.6.1`, `go_router ^14.6.2`, `drift ^2.21.0`, `sqlite3_flutter_libs`, `dio ^5.7.0`, `shared_preferences ^2.3.3`, `intl`.
- ✅ Структура `lib/core/`, `lib/features/`, `lib/app/`, `lib/shared/`, `lib/l10n/` соответствует §2.
- ✅ `lib/app/router/` + `lib/app/app.dart` с shell-маршрутами Home / Reader / Settings / Search / Bookmarks.
- ✅ Поддержка Android/iOS сборок присутствует (`android/`, `ios/`, `tool/build_with_env.ps1`).

### 3.2 База данных (Drift) — ✅ Реализовано
- ✅ Drift-схема с таблицами `surahs`, `ayahs`, `words`, `translations`, `bookmarks`, `last_position`, `reading_history` (см. `lib/core/database/`).
- ✅ Версионирование миграций через `@DriftDatabase` (в коде есть upgrade-стратегии).
- ✅ DAO: `SurahDao`, `AyahDao`, `BookmarkDao`, `LastPositionDao`, `PositionDao` (тесты `position_dao_test.dart`, `last_read_position_test.dart`).
- ✅ Сидинг из `assets/quran_seed/quran_full.json` — `test/local_seed_integration_test.dart` зелёный.

### 3.3 Контент и доставка — 🟡 В процессе
- ✅ Базовый набор текста утхмани + переводы встроены (Kuliev, ru).
- ✅ `assets/quran_seed/quran_full.json` + генератор/CLI в `tool/`.
- 🟡 Контент-pipeline в виде манифеста/SHA256/ED25519 ещё не интегрирован в рантайм — есть стабы `tool/serve_manifest.dart`, `tool/sign_manifest.dart`, но автоматическое обновление из сети не подключено к приложению. Это пересекается с §10.

### 3.4 UI чтения — ✅ Реализовано
- ✅ Список сур (`features/quran/...`) с поиском.
- ✅ Экран чтения с пагинацией, джузом, прогрессом.
- ✅ Закладки + список закладок (`features/bookmarks/`), запись `last_position` и `reading_history` работают (тесты `bookmark_notes_surah_test.dart`, `last_read_position_test.dart`).

### 3.5 Поиск (FTS5, базовый) — ✅ Реализовано
- ✅ Нормализация арабского — `test/arabic_normalizer_test.dart`.
- ✅ Поиск по аятам, словам, транслитерации (`test/ayah_search_test.dart`, `words_search_test.dart`, `surah_search_test.dart`, `ru_transliteration_search_test.dart`).
- 🟡 Подсветка совпадений в сниппете реализована частично (есть, но не во всех режимах поиска).

### 3.6 Настройки — ✅ Реализовано
- ✅ Тема, размер арабского шрифта, переключатель перевода (`features/settings/`, `features/reader_settings/`, `test/reader_display_settings_test.dart`).

### 3.7 Definition of Done MVP v0.1
