### Подзадача 3.1: Заменить sequential UPDATE на `db.batch()`

```dart

    for (final entry in metaMap.entries) {

      if (parts.length != 2) continue;
```

### Подзадача 5.2: Реализовать миграцию со старого формата

Первый запуск после обновления: прочитать 4 старых ключа, сериализовать в JSON, удалить старые.

```dart
Future<void> _ensureMigrated() async {
  // Один раз мигрируем в JSON-формат.
  if (_prefs.getString(_key) != null) return;
  final version = _prefs.getString(_appliedVersionKey);
  if (version == null) return; // nothing to migrate
  final hash = _prefs.getString('content.manifest.hash') ?? '';
  final payload = _prefs.getString('content.manifest.sha256');
  final appliedAt = _prefs.getString('content.manifest.applied_at') ?? '';
  final json = jsonEncode({
    'version': version,
    'hash': hash,
    'payload_sha256': payload,
    'applied_at': appliedAt,
  });
  await _prefs.setString(_key, json);
  await _prefs.remove(_appliedVersionKey);
  await _prefs.remove('content.manifest.hash');
  await _prefs.remove('content.manifest.sha256');
  await _prefs.remove('content.manifest.applied_at');
}
```
