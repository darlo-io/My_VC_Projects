# quran_app — Bugfix round 6 (2026-07-22) — tafsir loading ✅

User-подтверждено:
> теперь работает правильно. осталось исправить загрузку тафсира.

## Найденные root causes (2 штуки)

### 1. StreamBuilder не вызывал builder (Round 4-5)

В Round 4-5 UI зависел от `StreamBuilder.builder` callback'а:
```dart
StreamBuilder<List<Tafsir>>(
  stream: cached,  // watchByAyahAndSource
  initialData: const <Tafsir>[],
  builder: (context, snapshot) {
    if (!_fetchedFor) {
      _fetchedFor = true;
      unawaited(_fetch(source));  // ← запускался внутри builder'а
    }
    ...
  },
);
```

На устройстве c1316607 builder **не вызывался** (verified через
`stderr.writeln` в Round 4). Без `_fetchedFor=true` → без `_fetch`
→ infinite loading.

Попытки Round 5 добавить `initialData: const <Tafsir>[]` — не помогли
(verified 2026-07-22 22:36 — builder всё равно не вызывался).

### 2. Runtime TypeError в DTO (новый баг в Round 6)

При рефакторе на прямое чтение из DB обнаружилось:
```
type 'Null' is not a subtype of type 'num' in type cast
```

В `QuranComTafsirVerseDto.fromJson`:
```dart
id: (j['id'] as num).toInt(),  // ← j['id'] == null в /by_ayah response!
```

Quran.com v4 response для `/by_ayah/{key}` имеет структуру:
```json
{"tafsir":{
  "verses":{"1:1":{"id":1}},     ← id каждого verse внутри verses map
  "resource_id":170,
  "language_id":138,
  "text":"...",
  ...
}}
```

`id` существует только внутри `verses["1:1"].id`, **не на верхнем
уровне `tafsir` объекта**. Поэтому `(j['id'] as num)` падал с TypeError
на каждом /by_ayah запросе.

## Решение

### File 1: `lib/features/audio/data/quran_com_api.dart`

Сделал поля `id` и `verseKey` nullable, исправил casts:

```dart
factory QuranComTafsirVerseDto.fromJson(Map<String, dynamic> j) {
  return QuranComTafsirVerseDto(
    id: (j['id'] as num?)?.toInt(),            // ← nullable
    resourceId: (j['resource_id'] as num).toInt(),
    verseKey: j['verse_key'] as String? ?? '',  // ← nullable fallback
    languageId: (j['language_id'] as num?)?.toInt() ?? 0,
    text: (j['text'] as String?) ?? '',
  );
}
```

`id` nullable потому что `/by_ayah/{key}` не содержит этого поля
(только `/by_chapter/{id}` возвращает список verse'ов с их id).

### File 2: `lib/features/quran/presentation/widgets/tafsir_panel.dart`

**Полный рефакторинг: убрал StreamBuilder, `_fetchedFor`, `_slowLoadTimer`,
`watchByAyahAndSource`. Заменил на прямую state-машину**:

```dart
class _TafsirPanelState extends ConsumerState<_TafsirPanel> {
  TafsirSource? _selectedSource;
  bool _loading = false;
  String? _error;
  Tafsir? _fetchedTafsir;  // ← локальный state для результата
  
  Future<void> _selectSource(TafsirSource s) async {
    setState(() {
      _selectedSource = s;
      _fetchedTafsir = null;
      _error = null;
    });
    _lastTafsirSourceId[widget.ayah.id] = s.id;
    // **Запускаем fetch напрямую, без зависимости от StreamBuilder'а**
    unawaited(_fetch(s));
  }
  
  Future<void> _resolveInitial(int sourceId) async {
    final source = await ref.read(tafsirDaoProvider).getById(sourceId);
    if (!mounted || source == null) return;
    setState(() => _selectedSource = source);
    // После загрузки initial source'а — сразу запускаем fetch
    unawaited(_fetch(source));
  }
  
  Future<void> _fetch(TafsirSource source) async {
    setState(() {
      _loading = true;
      _error = null;
      _fetchedTafsir = null;
    });
    
    try {
      await ref.read(tafsirsSyncServiceProvider).fetchTafsirForAyah(
        ayahId: widget.ayah.id,
        surahId: widget.ayah.surahId,
        ayahNumber: widget.ayah.ayahNumber,
        tafsirSourceId: source.id,
      ).timeout(
        const Duration(seconds: 60),
        onTimeout: () => throw TimeoutException(...),
      );
      
      // **Round 6 bugfix**: прямое чтение из DB после успешного
      // fetchTafsirForAyah — без ожидания Drift watch stream
      final dao = ref.read(tafsirDaoProvider);
      final rows = await dao.getForAyah(
        widget.ayah.id, sourceId: source.id,
      );
      if (!mounted) return;
      if (rows.isEmpty) {
        setState(() { _loading = false; _error = 'Нет тафсира'; });
        return;
      }
      setState(() { _loading = false; _fetchedTafsir = rows.first; });
    } catch (e) {
      if (!mounted) return;
      // TimeoutException, TafsirNotFoundException, etc. → _error
      ...
    }
  }
  
  Widget _buildTafsirContent(AppLocalizations t, TafsirSource source) {
    // Прямая логика: success → error → loading
    if (_fetchedTafsir != null) {
      return SingleChildScrollView(child: Text(_stripHtml(_fetchedTafsir!.textValue)));
    }
    if (_error != null) {
      return Center(child: errorWidget with retry button);
    }
    return const Center(child: CircularProgressIndicator());
  }
}
```
