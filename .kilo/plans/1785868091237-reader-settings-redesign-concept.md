# Reader Top Bar & Settings — Redesign Concept

**Дата:** 2026-08-04  
**Объект:** верхняя control-панель `_AnimatedTopBar` (Reader) + полноэкранное меню `ReaderDisplaySettingsScreen`  
**Файлы под редизайн:**
- `lib/features/quran/presentation/reader_screen.dart` — `_AnimatedTopBar` (≈ строки 812–951), `_ReadingModeToggle` (≈ 1156–1209), `CircleIconButton` используется здесь и в других местах (`lib/shared/widgets/common_widgets.dart:203`)

## 1. Аудит существующего решения

### 1.1 Верхняя панель (`_AnimatedTopBar`)

```
┌──────────────────────────────────────────────────────────────┐
│  ⌃   ﷽  surah001                [📖 Построчно]  [⚙]          │
│  ←   Al-Fatihah • 7 аятов                                  │
└──────────────────────────────────────────────────────────────┘
```

- **Контейнер:** `background @ 92%`, золотая рамка `alpha 0.35`, blur-shadow `0.35`, `BorderRadius 20`. Внутри `Row` с тремя блоками.
- **Проблемы визуального стиля:**
  1. Pill-контейнер с **полупрозрачным фоном и яркой золотой рамкой** конкурирует с рамкой Mushaf-страницы — глаз постоянно «перескакивает» между двумя контурами.
  2. Заголовок суры — **золотой glyph-шрифт 24px + транслитерация 11px серым** — информационная иерархия слабая: glyph-имя визуально тяжелее, чем латинское, хотя по значимости для англо-/русскоязычного пользователя оно вторично.
  3. Кнопка режима чтения (`_ReadingModeToggle`) — **вертикальный stack: иконка сверху, label снизу**. Высота ≈ 44 dp, ширина ≈ 60 dp — выглядит как «костыль» на фоне плоских круглых кнопок по краям.
  4. Правый край: два одинаковых круглых `CircleIconButton` подряд (tune + back) — визуально монотонно.
  5. `Icons.tune` (ползунки) — плохо считывается как «настройки отображения», для большинства юзеров это «настройки вообще».
  6. Маркер «7 аятов» — мелкий серый текст 11px, легко пропустить.
- **Проблемы взаимодействия:**
  - **Только 2 контрола в ряд** (back + tune) при сенсорном тапе — не используется пространство. Reading-mode toggle теряется.
  - Нет индикации активного состояния (какая сейчас тема, какой режим).
  - Нет быстрого доступа к закладкам / поиску / тафсиру прямо из шапки — нужно открывать bottom-sheet.

**Проблемы экрана настроек:**
1. **Sticky preview занимает ~38% экрана** (kPreviewHeight = 280 на типичном 6" устройстве = ~360 dp экран, минус AppBar 56 dp). На реальном экране пользователь видит только верхние 1–2 слайдера без скролла.
2. **Sliders без snap-feedback**: тонкая дорожка `2px`, маленький thumb `8px`, разделители жёсткие (`divisions: 22`) — пользователь не чувствует «щелчки».
3. **Group headers** — 11px ALL-CAPS без визуального акцента, легко пропускаются.
4. **Chips для темы** — четыре неравных по ширине чипа в `Wrap`; при длинных локалях («Пергамент») чипы переносятся и теряют выравнивание.
5. **`_FontFamilyMenu`** — единственный контрол, реализованный как кастомный popup-menu (обходной путь из-за конфликта DropdownButton с GoRouter). Семантически это «раскрывающийся список», но визуально выглядит как кнопка — не интуитивно.
6. **Нет группировки «Пресеты»** (например, «Дневной», «Ночной», «Чтение перед сном», «Обучение»), хотя это самый частый сценарий «настроил один раз — забыл».
7. **Нет Live preview при выборе шрифта** — пользователь видит результат только в Reader после «Готово».
8. **Все действия на одной странице** — нет табов / accordion / stepper’а, всё «в кучу».

## 2. Концепция верхней панели

### 2.1 Принципы
- **Less, but better.** Минимум контролов в шапке; всё редкое — в overflow-меню (`⋮`).
- **Семантические иконки** — не абстрактные тюнеры, а действия.
- **Material 3 «Fluent»** — крупный touch-target (48dp), мягкие формы, моноконтрастная палитра.
- **Контекстный заголовок** — арабское имя + транслитерация + счётчик аятов + номер страницы Mushaf.
- **Состояние, видимое сразу** — активный режим чтения показан заполненной иконкой, текущая тема — цветной точкой.

### 2.2 Целевая компоновка (`Spec A` — рекомендуется)

```
┌────────────────────────────────────────────────────────────────────┐
│  ◀  ٱلْفَاتِحَة  Al-Fatihah · с. 1 / 604 · 7 аятов    🔖  ⏯   ⋮  │  56dp
└────────────────────────────────────────────────────────────────────┘
```

**Левая группа:** `◀ back` (32dp circle, gold-tint при hover)  
**Центр:** три строки, центрированные:
- L1 — арабское имя (Surah V2 glyph, 22px, gold)
- L2 — латинская транслитерация (13px, semibold, textPrimary)
- L3 — `с. N/604 · N аятов` (11px, textTertiary)
**Правая группа:**
- `🔖` закладка текущего аята — длинный press → список закладок суры, короткий → toggle
- `⏯` **mode pill** (как segmented control): одна иконка `≡` (lineByLine) **или** `▤` (book) с активным состоянием (filled bg)
- `⋮` overflow: [Настройки отображения, Тема, Шрифт, Перевод, Поделиться аятом, Копировать аят]

### 2.3 Цветовая палитра (Top Bar v2)

| Элемент | Цвет | AppColors | Альфа |
|---|---|---|---|
| Фон контейнера | `surface` (карточный белый) | `AppColors.surface` | 95% |
| Рамка | `gold` | `AppColors.gold` | 8% (была 35%) |
| Shadow | black | `Colors.black` | 6%, blur 16, dy 6 |
| Заголовок (араб.) | `gold` | `AppColors.gold` | 100% |
| Заголовок (лат.) | `textPrimary` | `AppColors.textPrimary` | 100% |
| Caption (страница/аяты) | `textTertiary` | `AppColors.textTertiary` | 100% |
| Активный mode pill | `gold` bg, `backgroundDeep` fg | — | 100% |
| Неактивный mode pill | прозрачный | — | — |
| Overflow icon | `textPrimary` | — | 80% |

### 2.4 Типографика

- **Заголовок суры (араб.)**: 22px / 1.1 height, w700, gold, шрифт `Surah Name V2`.
- **Транслитерация**: 13px / 1.2, w600, textPrimary. Семейство — Inter/SF/системный.
- **Caption**: 11px / 1.3, w500, textTertiary, `letter-spacing: 0.4`.
- **Overflow menu items**: 14px / 1.3, w500, textPrimary. Section headers — 11px caps textTertiary.

### 2.5 Иконки (Material Symbols Rounded, 22dp, w500)

| Действие | Иконка | Обоснование |
|---|---|---|
| Back | `arrow_back` | стандарт |
| Закладка toggle | `bookmark` (outline) ↔ `bookmark` (filled) | семантически ясно |
| Mode lineByLine | `view_agenda_outline` | колонки |
| Mode book | `auto_stories` | открытая книга (стиль Mushaf) |
| Overflow | `more_horiz` | 3 точки, более «десктопно» чем `more_vert` |
| Theme quick | `palette` (в overflow) | цветовая тема |
| Settings | `tune` (в overflow) | настройки отображения |
| Share ayah | `share` (в overflow) | «поделиться аятом» |
| Copy ayah | `content_copy` (в overflow) | копировать текст + ссылку |

### 2.6 Отступы и размеры

- Контейнер: `margin: 8dp sides, 4dp top`, `padding: 8dp H × 6dp V`.
- Высота контейнера: **56dp** (стабильная, не зависит от контента).
- Минимальная высота touch-target: 44dp (Apple HIG) / 48dp (Material) — у нас 44dp (компромисс под маленький экран).
- Между элементами `Row`: 4dp (tight) — экранное пространство дорого.
- Border-radius: **20dp** (был 20dp — сохраняем, но уменьшаем рамку, чтобы выглядел «легче»).
- Blur-shadow: blur 16, dy 6, alpha 0.06 — мягче текущего (0.35) в ~6 раз.

### 2.7 Альтернативные компоновки

**Spec B — Floating Glass** (минимализм):
```
┌──────────────────────────────────────────────────┐
│         ٱلْفَاتِحَة                                │
│         Al-Fatihah · 7 аятов                       │
│    ◀                                  ⚙          │
└──────────────────────────────────────────────────┘
```
- Заголовок строго центрирован, контролы «плавают» по краям.
- Плюс: максимум места для текста. Минус: overflow-меню прячет слишком много.

**Spec C — Compact Icon Row** (только иконки):
```
┌──────────────────────────────────────────────────┐
│  ◀  ﷽   ⌃⇩  ≡  🔖  ⏯  Aa  🌙  ⋮                │
└──────────────────────────────────────────────────┘
```
- 8 иконок подряд. Плюс: всё видно. Минус: перегруз, нет визуального центра, мелкие touch-target.

**Рекомендация:** **Spec A** — баланс между информативностью и простотой.

## 3. Концепция меню настроек

### 3.1 Целевая структура (навигация)

Используем **Bottom-sheet с табами** вместо full-screen push — это даёт:
- мгновенный доступ без потери контекста чтения,
- live-preview всего экрана «под» шторкой (60–70% экрана),
- свайп вниз для закрытия (без лишнего диалога «Discard changes»).

```
┌─────────────────────────────────────────┐
│  ═══════════ (drag handle)             │
│                                         │
│  [ Текст ] [ Макет ] [ Тема ] [ Ещё ]  │  ← TabBar (4 вкладки)
│                                         │
│  ── Tab content ──                      │
│                                         │
│  ┌─────────────────────────────────┐   │
│  │ ... (зависит от вкладки)         │   │
│  └─────────────────────────────────┘   │
│                                         │
│  [ Пресеты: 🌙 Ночной  ☀️ День  📚 Учёба ] │  ← горизонтальный chip-row
│                                         │
│         [ Сбросить ]   [ Готово ]        │
└─────────────────────────────────────────┘
```

### 3.3 Пресеты (chip-row)

Три быстрых пресета = «магическое» упрощение для пользователя, который не хочет копаться в 12 слайдерах:

| Пресет | font | size | line | theme | translation |
|---|---|---|---|---|---|
| 🌙 Ночной | Amiri | 30 | 2.4 | Dark | on, 14 |
| ☀️ День | Amiri | 28 | 2.2 | Light | on, 14 |
| 📚 Учёба | Amiri | 32 | 2.6 | Parchment | on, 18 |
| 🎯 Фокус | KFGQPC Uthman | 36 | 2.4 | Sepia | off |

Реализация — `class ReaderPreset { ... }` в `domain/`, `applyPreset(ReaderPreset p)` в `codec.dart`. Кнопка «Сбросить» в bottom-sheet — отдельная (с подтверждением).

### 3.7 Анимации

- Открытие bottom-sheet: `showModalBottomSheet` с `isScrollControlled: true`, `useSafeArea: true`, кривая `Curves.easeOutCubic`, длительность 320ms.
- Закрытие: свайп вниз ИЛИ тап на backdrop.
- Live-preview: изменение любого слайдера **мгновенно** применяется к `_draft`, и `_draft` рендерится в `PreviewAyah` (sticky-header в текущей реализации, либо full-screen под шторкой в новой).
- Применение пресета: анимация «волна» через `AnimatedSwitcher` на каждом контроле (350ms `Curves.easeInOut`).

## 9. Открытые вопросы (требуют решения пользователя)

1. **Bottom-sheet vs full-screen** — предлагаю bottom-sheet, но если пользователь привык к full-screen — оставим full-screen с табами (без sticky preview, который дублирует контекст).
2. **Арабское имя суры в Top Bar** — оставить glyph-шрифт 22px или заменить на обычный арабский 18px (более читаемо, но теряется Mushaf-стилистика)?
3. **Mode-pill в Top Bar vs overflow** — текущий toggle занимает 60dp ширины. Если перенести в overflow (через `view_agenda` / `auto_stories`), Top Bar станет «легче». Минус — на 1 тап больше для смены режима.
4. **Пресеты — 4 или больше?** Можно добавить «Custom» (запоминает текущие настройки как новый пресет). Усложняет UX, но даёт персонализацию.
5. **Default `paddingHorizontal` = 0 или 8?** Текущий 0 даёт «Mushaf-style» (текст у края), 8 — безопаснее для касаний. User feedback 2026-08-02 жалуется на 32dp, но 0 он не пробовал.
6. **Тафсир по умолчанию — где взять список?** Сейчас есть в `tafsir_dao.dart` (Curry, Jalalayn, Ibn Kathir — нужно проверить).
