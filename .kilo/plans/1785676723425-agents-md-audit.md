## 1. Lines 6–10 — Дублирующая (category: duplicate)

```markdown
## Assistant communication style

- **Be brief.** No filler, no verbose reasoning in the final reply.
- **Respond in Russian.** Match the user's language.
- **Ask when unclear.** If the user's request is ambiguous or missing
  information, ask clarifying questions instead of guessing.
```

**Problem:** Эти же правила уже прописаны в глобальных Kilo-instructions
(поле «Personality»: *"Be brief… Don't ask for more information than
necessary… ask with the question tool when you need an actual answer…
be direct and to the point… respond in Russian"*) — это
**system-prompt** уровня Kilo, а не проектный. Дублирование двух
инструкций в одном проекте даёт конфликт на «Ask when unclear» —
глобальная говорит «don't ask for more information than necessary»,
а локальная — «ask clarifying questions instead of guessing».
На практике они совместимы, но **раздел о communication style не
является проектно-специфичным** (см. строку 3: *"Project-specific
notes that are non-obvious. General Flutter/Dart rules live in the
global Kilo instructions"*).

**Рекомендация:** удалить раздел `## Assistant communication style`
целиком. Это не проектная информация, а user-preference, которая
должна жить в глобальной Kilo config (`.config/kilo/`), а не
в `AGENTS.md` репозитория.

## 4. Lines 53, 64, 67–76 — Нерабочая / устаревшая (category: broken / outdated)

### 4a. Line 53 — `install-mcp-flutter.ps1` lies about dependencies
```powershell

**Problem:** `tools/dev/install-mcp-flutter.ps1` существует (2530

текущего разработчика, но делает инструкцию **непортабельной**,
а AGENTS.md описан как документация для ассистента (любого
запуска).

**Рекомендация:** заменить на relative-команду
`dart compile exe` с явной проверкой `where dart` / `which flutter`,
либо просто указать «запустить `tools/dev/install-mcp-flutter.ps1`
после добавления Flutter SDK в PATH». Hardcode пути вынести в
README `tools/dev/`.

### 4b. Lines 63–65 — Bash внутри PowerShell-контекста
```markdown
- **После обновления upstream**:
  ```bash
  cd F:\My_VC_Projects\mcp_flutter && git pull
  pwsh tools/dev/install-mcp-flutter.ps1
  ```
```

**Problem:** В PowerShell `cd F:\...` через `&&` **работает в
PowerShell 7+**, но AGENTS.md выше (строка 81) рекомендует именно
PowerShell 5.1. На 5.1 `&&` **не поддерживается** — нужно `; if ($?) { ... }`.
Если ассистент копирует этот снипет в PS 5.1, он упадёт.

**Рекомендация:** использовать `;` вместо `&&`, либо явно указать
«PowerShell 7+ (pwsh)».

**Problem:** Точно так же hardcode `F:\dev\` — это **не

Ассистент, копирующий снипет, не сможет его запустить без
ручного создания `F:\dev\`.
