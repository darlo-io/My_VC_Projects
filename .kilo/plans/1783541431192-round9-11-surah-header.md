## Дизайн ornament (адаптивный)

| Параметр | Portrait (`width < 600dp`) | Landscape (`width >= 600dp`) |
|---|---|---|
| **aspectRatio** ornament-рамки | `600/230 ≈ 2.6` (натуральная) | `600/120 ≈ 5.0` (вытянутая по горизонтали) |
| **fontSize** (арабское название) | 64 (крупно, Mushaf-стиль) | 32 (компактно) |
| **innerPadding** | `horizontal: 72, vertical: 32` | `horizontal: 96, vertical: 12` |
| **Image.fit** | `BoxFit.fill` (растягиваем ornament) | `BoxFit.contain` (центрируем ornament PNG, не растягиваем) |
| **Image.alignment** | — | `Alignment.center` |

На viewport 360×792 (portrait): ornament **360×138** (компактный, ~17% от height).
На viewport 792×360 (landscape): ornament **792×158** (широкий, ~44% от height, вытянутый 5:1).

## Изменения

### `lib/features/quran/presentation/widgets/reader_widgets.dart:SurahHeader`

Заменить весь class body на новый адаптивный вариант:

```dart
class SurahHeader extends StatelessWidget {
  const SurahHeader({
    required this.surahNumber,
    required this.textColor,
    super.key,
  });

  /// Номер суры 1..114. Используется как glyph-key в
  /// `Surah Name V4.ttf` для арабского названия.
  final int surahNumber;

  /// Цвет основного текста Quran (из `ReaderPalette`).
  final Color textColor;

  static const String _frameAsset =
      'assets/images/ornaments/surah_header_frame.webp';

  /// Aspect ratio ornament PNG (600×230 ≈ 2.6). В portrait
  /// используется напрямую; в landscape ornament становится
  /// вытянутым по горизонтали (5:1) — компактнее по высоте.
  static const double _frameAspectRatioPortrait = 600 / 230;
  static const double _frameAspectRatioLandscape = 600 / 120;

  /// Адаптивные размеры шрифта. Portrait — Mushaf-стиль (крупно).
  /// Landscape — компактно (чтобы ornament не доминировал).
  static const double _fontSizePortrait = 64;
  static const double _fontSizeLandscape = 32;

  /// Внутренний padding. В landscape ornament более вытянутый,
  /// ornament-узоры по бокам — нужно больше места.
  static const EdgeInsets _paddingPortrait = EdgeInsets.symmetric(
    horizontal: 72, vertical: 32,
  );
  static const EdgeInsets _paddingLandscape = EdgeInsets.symmetric(
    horizontal: 96, vertical: 12,
  );

  @override
  Widget build(BuildContext context) {
    return Padding(
      // Внешние отступы.
      padding: const EdgeInsets.fromLTRB(4, 24, 4, 16),
      child: LayoutBuilder(
        builder: (context, constraints) {
          final width = constraints.maxWidth;
          if (width <= 0) return const SizedBox.shrink();
          final mediaSize = MediaQuery.sizeOf(context);
          final isLandscape = mediaSize.width >= 600;

          final aspectRatio = isLandscape
              ? _frameAspectRatioLandscape
              : _frameAspectRatioPortrait;
          final fontSize = isLandscape
              ? _fontSizeLandscape
              : _fontSizePortrait;
          final padding = isLandscape
              ? _paddingLandscape
              : _paddingPortrait;
          final height = width / aspectRatio;

          return SizedBox(
            width: width,
            height: height,
            child: Stack(
              fit: StackFit.expand,
              children: [
                // Ornament-рамка.
                Image.asset(
                  _frameAsset,
                  fit: isLandscape ? BoxFit.contain : BoxFit.fill,
                  alignment: Alignment.center,
                  filterQuality: FilterQuality.medium,
                ),
                // Арабское название суры.
                Padding(
                  padding: padding,
                  child: Center(
                    child: FittedBox(
                      fit: BoxFit.scaleDown,
                      child: Text(
                        surahNameGlyph(surahNumber),
                        textDirection: TextDirection.rtl,
                        textAlign: TextAlign.center,
                        maxLines: 1,
                        style: TextStyle(
                          fontSize: fontSize,
                          fontWeight: FontWeight.w400,
                          color: textColor,
                          // V4 шрифт — PUA-codepoints из
                          // `Surah Name V4.ttf`. Зарегистрирован в
                          // pubspec.yaml (см. fonts: family: Surah Name V4).
                          fontFamily: surahNameV4FontFamily,
                          height: 1.0,
                          letterSpacing: 0.5,
                        ),
                      ),
                    ),
                  ),
                ),
              ],
            ),
          );
        },
      ),
    );
  }
}
```

## Возможные блокеры

**Q1: V4 vs V2 стиль глифов — разные?** V4 используется в SurahList (компактный, для tile), V2 в SurahHeader (классический Mushaf). Они оба используют одинаковые PUA codepoints (U+E001..U+E072) — оба кодируют одни и те же арабские названия, но визуально разные глифы. Пользователь явно просил V4 для SurahHeader — это **новый** стиль ornament'а (более минималистичный).

**Q2: BoxFit.contain в landscape** — ornament PNG (600×230) центрируется в Container (792×158). Слева/справа остается ~50dp пустого пространства. Пользователь просил "вытянутый по горизонтали" — это правильно.

**Q3: MediaQuery.sizeOf vs MediaQuery.of** — `sizeOf` не выбрасывает исключение если MediaQuery отсутствует выше, более безопасно.
