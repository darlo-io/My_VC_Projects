# quran_app — Bugfix round 7 (2026-07-22) — UX улучшения для не-русских тафсиров

## Контекст user feedback
> при выборе «Ибн Касир» или других источников кроме «Ас-Саади»,
> язык тафсира не русский.

## Реальная проблема
**Это не баг кода — это ограничение Quran.com API.**

Quran.com v4 API возвращает 20 тафсиров на разных языках:
- 1 русский: **Ас-Саади (русский перевод)** — id=170
- 18 арабских: Ибн Касир, Ат-Табари, Муяссар, Аль-Куртуби, Ас-Саади (Arabic edition), Ат-Тантави, Аль-Багави, Ат-Табари (Tafsir al-Tabari Arabic), Фатх уль-Маджид, и др.
- 1 урду: Байан уль-Куран
- 1 курдский: Ребарский тафсир
- Несколько бенгали

**Нет русских переводов для арабских/урду/бенгальских тафсиров.**

Даже `Tafsir Ibn Kathir` (id=14, самый популярный) возвращает только оригинальный арабский текст — Quran.com не имеет русского перевода для него.

## Решение (UI improvements)

Не пытаемся решить data-проблему (нет данных), а делаем UX прозрачным:
1. **Subtitle в source picker** с типом тафсира: «Ибн Касир (бенгальское изложение)»
2. **RTL + арабский шрифт** для арабского/урду/курдского текста тафсира
3. **Предупреждение** под иностранным тафсиром: «Quran.com предоставляет только оригинал на арабском. Перевода на русский для этого тафсира нет.»
4. **Бейдж с кодом языка** (AR/RU/UR/BN/KU/EN) в source picker'е

## Изменения

### `lib/features/quran/presentation/widgets/tafsir_panel.dart`

Добавлены helper-функции и `_LangBadge` widget:

```dart
/// **Round 7 (2026-07-22)**: определение RTL-языка для арабских
/// текстов. Арабский, урду и курдский (Sorani) — RTL.
bool _isRtlLanguage(String? code) {
  switch (code) {
    case 'ar': case 'ur': case 'ku': case 'fa': case 'he':
      return true;
    default:
      return false;
  }
}

/// Полное название языка на UI-языке пользователя.
String _languageDisplayName(String? code) {
  switch (code) {
    case 'ar': return 'Арабский оригинал';
    case 'ur': return 'Урду';
    case 'bn': return 'Бенгальский';
    case 'ku': return 'Курдский (сорани)';
    case 'en': return 'English';
    case 'ru': return 'Русский';
    default: return code ?? '';
  }
}

/// Предупреждение под текстом иностранного тафсира.
String _languageWarning(String? code) {
  switch (code) {
    case 'ar':
      return 'Quran.com предоставляет только оригинал на арабском. '
             'Перевода на русский для этого тафсира нет.';
    ...
  }
}

class _LangBadge extends StatelessWidget {
  // Цветной бейдж с кодом языка (зелёный AR, золотой RU, синий UR...)
}
```

В `_buildSourceList` — subtitle с `_languageDisplayName(s.languageCode)` и trailing с `_LangBadge(code: s.languageCode)`:

```dart
return ListTile(
  leading: const Icon(Icons.menu_book_outlined, color: AppColors.gold),
  title: Text(displayName, ...),
  subtitle: showLangBadge
      ? Text(_languageDisplayName(s.languageCode), ...)
      : null,
  trailing: showLangBadge ? _LangBadge(code: s.languageCode) : null,
  onTap: () => _selectSource(s),
);
```

В `_buildTafsirContent` — RTL и предупреждение:

```dart
if (_fetchedTafsir != null) {
  final text = _stripHtml(_fetchedTafsir!.textValue);
  final isRtl = _isRtlLanguage(source.languageCode);
  final textWidget = Text(
    text,
    textAlign: isRtl ? TextAlign.right : TextAlign.left,
    textDirection: isRtl ? TextDirection.rtl : TextDirection.ltr,
    style: TextStyle(
      fontSize: isRtl ? 18 : 14,
      fontFamily: isRtl ? 'Amiri' : null,           // ← арабский шрифт
      fontFamilyFallback: isRtl ? ['Scheherazade'] : null,
    ),
  );
  return SingleChildScrollView(
    child: Column(
      children: [
        if (_isForeignLanguage(source.languageCode))
          Row(children: [_LangBadge(code: source.languageCode), Text(_languageWarning(...))]),
        textWidget,
      ],
    ),
  );
}
```

## Что НЕ покрыто этим фиксом

**Содержательный перевод на русский не предоставляется**. Это ограничение upstream'а (Quran.com). Чтобы получить реальный русский текст для Ibn Kathir/At-Tabari/etc., нужно:
1. Переключиться на другой API (например, `tanzil.net` или собственный backend с переводами)
2. Или интегрировать машинный перевод (Google Cloud Translation API, требует API key и платный)
3. Или собрать свой датасет переводов (большой объём работы)

Round 7 делает только UX-прозрачность — пользователь сразу видит, что тафсир не на русском.
