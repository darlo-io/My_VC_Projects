# quran_app — Bugfix round 8 (2026-07-23) — переводы Корана из Quran.com

User-запрос: добавить выбор переводов Корана (в дополнение к Кулиеву).
Сейчас в БД 2 переводчика (Кулиев, Sahih International), оба из alquran.cloud.
В Quran.com API доступно 126 переводов, включая 3 русских (Кулиев,
Ministry of Awqaf Egypt, Abu Adel).

## План (3 этапа, ~5-7 дней)

### Этап 1 (1-2 дня) — Добавить translators из Quran.com
- `lib/features/audio/data/quran_com_api.dart` уже содержит
  `QuranComReciterDto`, добавить **DTO для translation**:
  `QuranComTranslationDto` с id, name, author_name, language_name,
  slug.
- Создать `lib/features/quran/data/quran_com_translation_api.dart` —
  Dio client с двумя endpoint:
  - `GET /resources/translations` → list translations
  - `GET /quran/translations/{id}?verse_key={N:V}` → text для аята
  - `GET /quran/translations/{id}?chapter_number={N}` → вся сура (для bulk)
- Создать миграцию `translators` schema → v15→v17:
  - добавить `quran_com_id INTEGER` колонку в `translators`
  - добавить `name_ru TEXT` колонку (название перевода на русском)
- В `LocalSeedService.ensureSeeded()` добавить hardcoded
  список русских переводов из Quran.com API:
  - id=45: «Кулиев» (already exists in DB)
  - id=78: «Elmir Kuliev» → id=45 уже есть
  - id=78: «Russian Translation (Ministry of Awqaf)»
  - id=79: «Abu Adel»
- Сделать backfill миграцию translators с quran_com_id и nameRu
  из hardcoded маппинга (если в существующей БД поле null — заполнить)
- `app_preferences.dart`: добавить `activeTranslatorId` int?
  (default = 1 = Кулиев)

### Этап 2 (1-2 дня) — Обновить UI переключения
- `lib/features/settings/presentation/settings_screen.dart:213`:
  `_showTrSheet` показывает hardcoded `['ru', 'en']`. Заменить
  на reactive список translators из БД с language_code='ru':
  ```dart
  final translators = ref.watch(translatorsByLangProvider('ru'));
  ```
- Вместо `setTranslationLang('ru')` → `setActiveTranslatorId(id)`
- `QuranRepository.watchTranslationsForAyah` — добавить
  параметр `translatorId`, заменить фильтр `language_code`
- `reader_screen.dart` — использовать `prefs.activeTranslatorId`
  вместо `translationLang`

### Этап 3 (2-3 дня) — Lazy fetch для не-Кулиев переводов
- При первом выборе translator'a, чьи translations ещё не в БД:
  - запустить background fetch всех 6236 аятов через
    `GET /quran/translations/{id}?chapter_number={N}` для каждой сурah
  - сохранить через `TranslationDao.bulkInsert(translatorId, verses)`
  - показывать progress в UI («Загружаем перевод...»)
- Это делается через `QuranTranslationSyncService` (новый singleton)
- Когда translation полностью синхронизирован — UI показывает перевод
- При отсутствии сети — fallback на Кулиев (id=1) или пустой текст
