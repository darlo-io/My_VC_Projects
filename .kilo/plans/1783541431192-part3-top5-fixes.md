## Fix #3 (C3): `applyNameOverrides` через `db.batch()`

**Файлы:**
- `lib/features/audio/data/reciters_repository.dart:397-419`
- возможно нужно добавить метод в `ReciterDao`

### Подзадача 3.1: Добавить batch-update метод в `ReciterDao`

```dart
Future<int> updateNameRuBatch(List<({int id, String nameRu})> updates) {
  if (updates.isEmpty) return 0;
  return update(reciters)
      .where((r) => r.id.isIn(updates.map((u) => u.id)))
      .write(
        RecitersCompanion.custom(
          nameRu: updates.first.nameRu,
        ),
      );
}
```

Wait — это не batch with different values. Нужно **batch.update** с per-row updates.

### Подзадача 3.1 (refined): Правильный batch

```dart
/// Batch-update `nameRu` для нескольких reciters за 1 transaction.
/// Возвращает количество обновлённых строк.
Future<int> updateNameRuBatch(List<(int id, String nameRu)> entries) {
  if (entries.isEmpty) return 0;
  return transaction(() async {
    int updated = 0;
    for (final (id, name) in entries) {
      final n = await (update(reciters)
            ..where((r) => r.id.equals(id)))
          .write(RecitersCompanion(nameRu: Value(name)));
      updated += n;
    }
    return updated;
  });
}
```

### Подзадача 3.2: Refactor `RecitersRepository.applyNameOverrides`

```dart
Future<int> applyNameOverrides() async {
  final all = await _dao.getAll();
  final updates = <(int, String)>[];
  for (final r in all) {
    final id = r.mp3quranId;
    if (id == null) continue;
    final override = kReciterRuNames[id];
    String? newName;
    if (override != null) {
      newName = override;
    } else if (looksLikeBrokenRussian(r.nameRu ?? '')) {
      newName = r.nameEn;
    }
    if (newName != null && newName != r.nameRu) {
      updates.add((r.id, newName));
    }
  }
  return _dao.updateNameRuBatch(updates);
}
```
